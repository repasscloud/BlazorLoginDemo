This section documents the Cinturon360 HTTP API.

The API is tenant-scoped, versioned, and region-specific.  
Access is available only to approved vendors, TMCs, and clients under an active commercial agreement.

Use the pages in this section to understand versioning rules, regional endpoints, and tenancy-based access models.
