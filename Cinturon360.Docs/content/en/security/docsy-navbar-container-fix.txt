2) SCSS (replace your current td-content rules with this)

.td-content--container {
  /* Always keep the title/content below the fixed navbar */
  padding-top: calc(var(--td-navbar-height, 4rem) + 1rem);

  /* Do NOT add left/right padding here if you're using a Bootstrap .container inside.
     The container already provides the correct horizontal alignment. */
  padding-left: 0;
  padding-right: 0;
}

/* The H1 is no longer a direct child of .td-content, so target it correctly */
.td-content--container .container > h1 {
  margin-top: 0;
}

/* Optional: if you want extra breathing room under the title */
.td-content--container .container > h1 + .lead {
  margin-top: 0.75rem;
}

Notes:
- Remove these old rules (they break container alignment and/or don't apply):
  - .td-content { padding-left/right: ... }
  - .td-content > h1 { margin-top: ... }   (your h1 is not a direct child anymore)
- If you still want more/less vertical space, change only the '+ 1rem' above.
