## Affected components

This release includes changes to the following components:

- **Web application**
- **Public API**
- **Database / SQL layer**
- **CLI tooling**

Mobile and desktop applications are **not affected** in this release.

---

## Changes by component

### Web application
- Improved policy evaluation visibility during booking workflows
- Minor UI refinements for improved clarity and consistency
- Improved handling of edge-case approval states

---

### Public API
- Standardised correlation identifiers across request lifecycles
- Improved error response structure for invalid or rejected requests
- Additional metadata exposed for audit and reconciliation purposes

---

### Database / SQL
- Optimised query paths for frequently accessed reference data
- Minor schema consistency improvements (no breaking changes)
- Improved internal indexing for audit-related queries

---

### CLI
- Improved output consistency for status and diagnostic commands
- Minor performance improvements when querying large datasets

---

## Fixes

- Fixed an issue where some approval states were not reflected correctly in rare cases
- Corrected timestamp inconsistencies in certain audit records
- Resolved a concurrency issue affecting high-volume search requests

---

## Known limitations

The following items are known and planned for a future release:

- Additional export capabilities for large reports
- Extended environment visibility for administrators
